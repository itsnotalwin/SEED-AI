04 / THE EXPERIMENT

Not a wrapper.
A beginning.

SEED-0 is a tiny neural character model with trainable embeddings, a hidden layer, and a softmax output. We wrote the maths and training code ourselves, including backpropagation. It starts with random weights and no language understanding.

THE ENGINE

— parameters

Three-character context. Predicts one next character. It learns statistical patterns, not human-style understanding.

THE MEMORY

Portable by design

Explicit Q&A memories are retrieved when similar questions come up. They are not model weights and can be exported or deleted.

THE ROAD AHEAD

Research, not hype

Next: proper tokenisation, longer-context architectures, curated datasets, evaluations, opt-in contributions and improved training.

THE BOUNDARIES

Private by default

No third-party API calls. No chat upload. No community training. No remote accounts. Browser data can still be lost if cleared.

This prototype deliberately does not claim to be a useful general assistant. Building one from randomly initialised weights will require far more training data, experiments and compute.
